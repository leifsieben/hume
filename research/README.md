# Research scripts

One-off analyses kept for provenance. Each answered a question at a point in time; none is part
of the package, the test suite, or the figure pipeline, and none is maintained.

They are here rather than deleted because several numbers in `METHODS.md` and
`docs/selection/` came out of them, and a result whose script no longer exists is not
reproducible. Expect them to need editing to run: paths, corpus locations and API names have
moved on.

For anything current, use `tools/` (maintained utilities), `verification/` (the exactness
oracle), or `figures/src/` (the plates).
